# go-embed

[![Go Reference](https://pkg.go.dev/badge/github.com/embedas/go-embed.svg)](https://pkg.go.dev/github.com/embedas/go-embed)

Embed.as API client written in Go (golang), for fetching embeddable media to include in Write.as blogs.

It includes support for both Embed.ly and [Embed.as](https://embed.as), a service for embedding rich content, made by [Musing Studio](https://musing.studio).

## Supported Providers

- Airtable
- Are.na
- Bandcamp
- Bluesky
- Codepen
- Flickr
- Giphy
- GitHub Gists
- Imgur
- Instagram
- Kickstarter
- Mixcloud
- SoundCloud
- Spotify
- Tumblr
- Typeform
- Twitter / X
- Vimeo
- YouTube

## No Longer Supported

- **Cinnamon** — shut down ~2014
- **CloudApp / Zight** — proprietary API, no embed support
- **Gfycat** — shut down September 2023
- **Hype Machine** — no embed API
- **Last.fm** — no embed API
- **Quora** — no embed API
- **Rdio** — shut down November 2015
